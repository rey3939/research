# 引張試験 実験準備スケジュール

[PDFをダウンロード・確認する（A4・3ページ）](tensile_test_preparation_schedule.pdf)

組み立てた同期目印ホルダを使い、永久磁石エラストマーのヤング率・ポアソン比測定へ進むための準備をチェック欄付きでまとめました。

1. 治具・カメラ・可動点・固定点・縮尺・動画とCSVの同期を、試料なしで確認する。
2. 試験片ごとに寸法と標線を記録し、取り付けと初期状態の記録を行う。予備試験を1本実施してから本試験へ進む。
3. 試験片ごとの記録シート。幅・厚み・断面積・初期標線間隔・初期幅・予荷重・速度・記録間隔・撮影設定・縮尺・ファイル名を記入する。

時刻や所要時間を新たに割り当てず、前の回答の実施順を整理した資料です。10 mm/minはこれまでの設定として記載しています。カメラと画像計測の精度を確認するため、幅約120 px・縦ひずみ1％・ポアソン比0.5を仮定した幅変化約0.6 pxの例も載せています。

[同期目印ホルダの組立手順書](../../cad/tensile-sync-side-clamp-s50-m4x12/assembly-manual/README.md)

再生成は `python source/build_schedule.py`。PyMuPDF、fontTools、システムのNoto Sans CJKフォントを使用します。PDFの日本語テキスト抽出・ページ数・配置を確認し、プレビューを目視確認しています。結果は[validation.json](validation.json)に記録しています。
