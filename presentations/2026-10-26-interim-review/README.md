# 中間審査会スライド 改良版（10分発表用）

大橋 怜倭さんの添付発表資料（2026.10.26）をもとに再構成したスライドです。本文13枚＋補足7枚で、本文の発表時間は約10分を想定しています。

## ファイル

- `research_slides.pptx`：編集用PowerPoint。本文・模式図・数値比較図を編集できます。実測グラフの一部は元資料からの画像です。発表者ノートに説明原稿を収録しています。
- `research_slides.pdf`：表示確認用PDF。全20ページで、画像ベースです。
- `speaker_notes.md`：発表原稿、時間配分、変更点、原資料との対応、研究上の確認事項。
- `research_slides_bundle.zip`：上記3ファイルをまとめたもの。

GitHubで各ファイルを開き、ファイル画面のダウンロード操作で端末へ保存してください。PowerPointはダウンロード後にPowerPointなど対応アプリで開いてください。

## 改良の要点

1. 文字を減らし、背景・材料・線形性・実験配置を図で説明。
2. 線形性が磁場から曲げ量への換算を簡単にすることを、実験結果より先に説明。
3. 永久磁石エラストマーの広い弾性領域を、材料選択の利点として説明。
4. 感度と線形性を区別し、今回の条件では厚み4 mm・計測位置15 mmが有望であることを提示。
5. 実験結果と今後のモデル構築・材料特性測定を区別。

## 確認事項

元資料には本試料の弾性限界・荷重除去後の回復性の定量データがないため、検証済みの実験結果としては扱っていません。概念図と実測値を区別しています。詳細は `speaker_notes.md` を参照してください。

PowerPointの指定フォントはNoto Sans CJK JPです。開く端末にフォントがない場合は置換と表示を確認してください。PDFは共有する描画レイアウトから作成した確認版で、Microsoft PowerPointでの描画確認は実施していません。
