# 実験からモデル解析へ

更新した「磁束密度測定」の結果から、モデル解析の目的へつなぐ、16:9の1枚スライドです。

- `experiment_to_model_editable.pptx`：本文の図・文字を編集できるPowerPoint。ノート欄に約1分の発表原稿があります。
- `experiment_to_model_preview.pdf`：1ページのプレビュー。
- `experiment_to_model_preview.png`：画像プレビュー。
- `speaker_notes_ja.txt`：発表原稿と補足。

「磁束密度測定」の結果説明の後、「フローチャート／モデル構築」の前に置く構成です。PowerPointで元資料へ移すときは、スライド全体をコピーし、「元の書式を保持」で貼り付けてください。

内容は「実験で分かったこと → 実測だけでは分からない問い → モデルで調べること」の3段階です。実測との対応を確認し、領域別の磁場変化から感度・線形性を説明し得る機構を定性的に検討する、という位置づけです。

元資料の実験範囲に合わせ、位置比較は t=1 mm、厚み比較は測定位置−5〜15 mmと記載しています。「厚みを変えても線形性が完全に不変」とは主張していません。

元資料の見出し線・ロゴ・フッターを利用しています。本文の図はPowerPointの図形・線・テキストで構成し、写真や画像として貼り付けていません。フォントはYu Gothicです。PDFプレビューの生成時は日本語フォントの代替としてNoto Sans CJK JPを使用しています。
