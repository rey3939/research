# 線形性を説明するためのモデル解析

ユーザーが指定した次の流れに沿って作り直した、編集可能な1枚のPowerPointです。

曲げによる形状変化 → 各部の磁場変化の重ね合わせ → 実測では高い線形性 → なぜ？ → 実測の合計値からは領域別の寄与が分からない → 数値解析で全要素の磁場を計算し、領域別に調べる。

- `experiment_to_model_editable.pptx`：本文を図形・線・テキストで作成した16:9の1枚。ノート欄に発表原稿と補足があります。
- `experiment_to_model_preview.pdf`：1ページのプレビュー。
- `experiment_to_model_preview.png`：画像プレビュー。
- `speaker_notes_ja.txt`：発表原稿と補足。

「磁束密度測定」の実験結果の後、モデルのフローチャートの前に置く想定です。元資料へ移す際はスライド全体をコピーし、「元の書式を保持」で貼り付けてください。

線形性の観察範囲は、添付資料のt=1 mm、先端変位0〜4 mm、固定端側から中央寄りを指します。全ての測定位置・変位で線形という主張ではありません。右上のグラフは応答の概念図であり、実測値のプロットではありません。中央の破線は領域別の寄与を示す模式表示で、磁力線ではありません。

モデルで得られる寄与を実物の真値とせず、実測の傾向との対応を確認して、線形性を説明し得る機構を定性的に検討する位置づけです。粘弾性の時間依存性そのものを、この静的解析で解明するという意味ではありません。

元資料の見出し線・ロゴ・フッターを利用しています。本文の図・文字はPowerPointで編集できます。フォントはYu Gothic、PDFプレビュー生成時の代替フォントはNoto Sans CJK JPです。
