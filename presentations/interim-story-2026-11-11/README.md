## 研究のストーリー

**柔らかい対象の曲げを測りたい → PMEを使う → 感度だけでなく線形性が必要 → 実測で厚み・位置依存を確認 → 原因の仮説 → 予定の1次元追従モデルで定性的に検証 → 設計指針へ**

実験で入出力を定量評価し、モデルで主要傾向の定性的な再現を調べる、という位置づけです。解析値を真値として扱ったり、モデルとの不一致を粒子追加回転の証明としたりしません。

今回の実施予定は、ユーザーが示した1次元追従モデルと、ヤング率・ポアソン比の測定にそろえました。元資料の後半にある過去のCT、動的実験、断面・内部構造を追加する複数モデルの計画は、新しい予定として採用していません。

## 図とグラフの編集について

**すべて図形・線・テキストボックスで作成しており、画像の貼付けはありません。** 材料、柔らかいロボット、実験配置、曲げ形状、磁化方向、フロー、棒グラフ、散布点、軸、ラベルをPowerPoint上で直接編集できます。図は関連するまとまりごとにグループ化しています。

散布図は、元PDFのベクトル描画からプロット記号の位置を取得し、位置を保持して図形化しました。円・三角・四角・ひし形の輪郭も引き継いでいます。元の記号のベジェ輪郭は、細かい線分へ変換しています。元資料の赤い注釈丸は引き継いでいません。

元データのCSVを再解析したものではありません。新しい測定値、誤差棒、R²、非線形誤差を作成していません。散布図のy値を読み取って数値データとしたものでもありません。[source_plot_vectors.json](data/source_plot_vectors.json)には元PDF上の記号の位置・輪郭を保存しています。棒グラフは元資料の表示値0.097、0.203、0.333、0.478から描画しています。

概念図・仮説図・モデルの方法図は模式図です。解析結果は未取得として扱い、モデルと実測が既に一致したように見える重ね描きは使っていません。

## 研究上の表現を整理した点

- **実測と仮説と計画**を、見出しと色で区別しました。実測は青緑、仮説と今後のモデルは橙です。
- **線形性の意義**を結果の前に説明しました。同じ入力増分に対して出力増分が一定で、傾き・切片から換算しやすくなることを概念図で示しています。
- **広い弾性領域**は材料選択の利点として図示しました。本試料で測定した弾性限界・除荷回復の結果とは扱っていません。戻る図は模式図です。
- 厚みの結果は「増加」と表現し、**厳密な比例**とはしていません。表面距離一定では、磁気量と内部の距離分布の両方が変わります。
- 「θが変位に比例するからBも比例する」「厚くて剛性が増したから形状が変わる」という説明を、確定原因として掲載していません。
- 「低感度だから外乱が小さい」「磁場変化が到達しない」は掲載せず、**固定部で曲げ感度が小さいという観測**を示しています。
- 「最適」は**測定範囲内で直線換算を重視した有望な候補**へ変更しました。4 mm・15 mmの感度0.478 mT/mm、R²＝0.998は元資料の値です。微小変位の検出分解能や対象に与える剛性は実証済みとしていません。
- モデルの回転は、ユーザー確認済みの **「母材の回転には追従し、粒子単独の追加回転を省く」** に統一しました。元資料35ページの「回転無し」はそのまま採用していません。
- 比較目的を **「主要傾向を定性的に再現できる範囲」** にしました。粒子追加回転が起こらないことや、その寄与率の証明とはしていません。
- モデル内で変形中の磁気モーメントは一定とします。同じ磁化を仮定して厚みを変える場合、総磁気モーメントは体積に対応させる必要があることを発表ノートで補足しました。
- 形状計算は元資料34ページの **曲げエネルギー＋先端変位の拘束項** に整理しました。外部磁場による駆動を扱う別の旧フローを混在させていません。有限ペナルティによる先端変位の残差も確認事項です。
- **Eは曲げ剛性の入力、νは横収縮の把握**と役割を分けました。単純な曲げエネルギー式にνが直接入るとは説明していません。材料測定は今後の予定です。

## 原資料の表記と確認済み条件

- 長さ40 mm、幅10 mm、厚み1～4 mm、SmFeN 30 vol.%、厚み方向着磁を使用。
- 粒子径は元資料p.28、30の**36 μm**に統一しました。p.26の「36 mm」は採用していません。
- 線形性の範囲は元資料p.13本文の「−5～15 mm、全厚み」と「t＝2・3・4」に統一しました。
- センサ距離は**試料表面が基準**、3回は**同一試料での繰返し**とユーザー確認済みです。独立3試料という表現は使っていません。
- 元資料の変位yを、説明中ではuと表記しました。磁束密度の成分はΔByです。座標z_sの正方向は固定端から自由端側、模式図では下向きです。
- 符号付き回帰係数aと、感度の大きさ|S|＝|a|を区別しました。
- PMFUEの0.536°/1%圧縮は元資料からの引用です。別材料・別変形なのでPMEへ係数を転用しません。原修士論文の新たな本文照合は行っていません。
- 参考文献は提供資料から転記しました。原著本文の新規照合や、今回の原因を文献で確定したという扱いはしていません。

## ファイルと表示の確認

PowerPointは游ゴシックを指定しています。PDFはNoto Sans CJKを埋め込んでおり、日本語を検索・選択できます。PDFは同じ配置定義から別途ベクトル描画した閲覧版です。Microsoft PowerPointによる実描画の確認は行っていません。

PowerPointの再読込、ZIP構造、ページ数、画像ゼロ、文字の幅・高さ、既知の表示値、図形の配置を検証しています。[validation.json](validation.json)に結果を記録しています。外付けHDD内の元ファイルは変更していません。

## 再生成

Python：python-pptx、PyMuPDF、fonttools。フォント：`/usr/share/fonts/opentype/noto/NotoSansCJK-{Regular,Bold}.ttc`。

```bash
python source/build_deck.py
```

入力PDFからプロット位置を取り直す場合は、元の48ページPDFを指定します。

```bash
python source/extract_source_vectors.py --pdf /path/to/source.pdf
python source/build_deck.py
```

この抽出処理は元PDFのページ配置に対応するものです。別レイアウトのPDFへ置き換える場合は、フレーム座標等の更新が必要です。
