# 一次関数的な磁場応答の要因検討

2026年11月23日改訂。ユーザーが指定した次の導入に合わせて作成した、編集可能な1枚のスライドです。

**粘弾性体の曲げに伴う形状変化 → 各要素の磁場の重ね合わせから複雑な磁場変化を予想 → 実測では一次関数で近似可能 → なぜ単純な関係になるのか → 実測だけでは各要素の影響が分からない → 要素ごとの磁場寄与を調べるために磁場計算を行う。**

元資料の「磁束密度測定」の後、モデルのフローチャートの前に置く想定です。スライド全体をコピーし、「元の書式を保持」で貼り付けてください。元資料の見出し線・ロゴ・フッターを利用しています。

一次関数で近似できるという記述は、添付実験資料のt=1 mm、固定端側から中央寄り、先端変位0〜4 mmという測定範囲を指します。材料・装置の全体が厳密な線形システムであると同定した、という意味ではありません。右上のグラフは概念図で、実測値のプロットではありません。

「複雑と予想」は複数の幾何学的な影響が重なることに基づく導入です。粘弾性体だから必ず非線形応答になると断定するものではありません。静的な形状モデルで粘弾性の時間依存性そのものを解明するという意味ではありません。

計算する磁場成分・変位範囲・測定点・評価方法を実験とそろえ、実測の特徴との対応を確認したうえで、各要素の寄与を説明機構として検討する位置づけです。モデル内の寄与をそのまま実物の真値とはしません。
