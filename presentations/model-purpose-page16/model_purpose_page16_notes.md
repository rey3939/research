# 16ページ：モデルの実施目的

【使用位置】添付PDF「中間審査会スライド_大橋怜倭.pdf」の16ページ「実施目的」の差し替え用です。15ページの節見出しと17ページの実施手順をつなぐ1枚です。

【説明原稿・約60〜75秒】
このモデルを用いる目的は、粒子回転を省いた単純なモデルで、どこまで磁場を推定できるかを明らかにすることです。先行研究では、別材料であるPMFUEを一様圧縮した場合、1パーセントの圧縮あたり0.536度の粒子回転が報告されています。本研究のPMEでも、粒子回転が磁場に関与する可能性を考えています。一方、同じ曲率で曲げる場合、試料を薄くすると厚さ方向のひずみ差が小さくなるので、粒子回転による磁場への影響も小さくできるのではないかと考えました。そこで、粒子単独の追加回転を省いたモデルを構築し、厚みごとに実測値と比較します。誤差の範囲内で一致する条件が見つかれば、その条件では回転の影響を省いて磁場を推定できることを支持します。これにより、回転の影響を省ける条件という学術的知見と、薄板PMEの磁場を単純なモデルで予測する設計基盤につなげます。

【前の実験結果との関係】
14ページでは厚い試料で感度が高くなることを示しています。一方、ここでは薄板化で単純モデルを使える条件を調べます。目的は異なるため、薄くするほど全てのセンサ性能が良くなると主張するものではありません。最終的には、感度・柔軟性・予測のしやすさを両立する設計につなげます。

【仮説の背景】
単純な梁の純曲げを考えると、中立軸からの距離zにおける軸方向ひずみは ε≈κz、表面ひずみの大きさは |ε|max≈κt/2 です。同じ曲率κであれば、厚みtが小さいほど厚さ方向のひずみ差が小さくなります。ただし、ひずみの縮小が磁性微粒子の追加回転や磁場寄与の縮小につながることは、今回検証する仮説です。図は、この可能性を説明するための模式図です。薄板化だけで影響が必ずゼロになると仮定していません。同じ荷重を与える場合は厚みによって曲率が変わるため、同じ曲率・変形条件での比較という前提が必要です。

【何の回転を省略するか】
添付資料17ページは「内部粒子は母材に完全追従」「粒子単独の回転を考慮しない」としています。このため本スライドも、母材に対する粒子単独の追加回転を省略するモデルとして表現しました。母材の並進・断面の回転に伴う磁化方向の変化を含めるか、磁化方向を全体座標で固定するかは区別が必要です。添付資料35ページには「回転無し」という表現もあるため、モデル実装時には、局所座標に追従する回転と粒子の追加回転を分けて定義してください。このスライドは、磁化方向を全体座標で固定する仕様を新たに決定するものではありません。

【0.536°の扱い】
0.536°／1%圧縮は、提供資料24ページに記載されたPMFUEの先行研究の報告値です。原論文・修士論文本文での定義や取得方法を追加確認したものではありません。個々の粒子が同じ向きに一律0.536°ずつ回るという意味で図示していません。PMFUEと本研究のPMEでは材料と変形条件が異なるため、数値をそのままPMEの曲げへ移植しないでください。図の回転角も報告値を縮尺通りに示したものではありません。

【一致から主張できる範囲】
モデルと実測が一致しても「粒子が回転していない」とは断定できません。妥当性を確認した比較の下で、評価した厚み・変位・計測位置・精度の範囲では、回転の寄与をモデルへ追加せずに予測できることを支持する、という操作的な結論になります。測定誤差やノイズ、境界条件、形状再現、磁化量、材料定数、数値離散化、断面変形などの不確かさを確認してください。比較データだけに合わせてパラメータを調整し過ぎず、複数条件や未使用データでも確認すると、単なる当てはめと予測能力を区別できます。薄い試料は信号が小さくなるため、低いS/N比で差が見えない状態を「寄与が小さい」と取り違えないことも必要です。

不一致の場合も、それだけで粒子回転を原因と断定できません。原資料17ページの「差が増大した厚み＝回転を無視できない」は、「差が増大した厚みで、回転等の追加効果の必要性を検討する」とすると、この目的と整合します。

【図の意味】
内部粒子の図、厚い／薄い試料、比較グラフは全て模式図です。粒子回転の測定結果、モデルが一致した結果、厚みの限界値が既に得られたことを示すものではありません。今後のモデル構築・検証の目的を説明しています。
