# 変形センサの比較：3ページ目の改良

ユーザー添付の6枚構成「プレゼンテーション1.pptx」の3ページ目を、2ページ目の要求「大変形への追従」「変形量への換算（線形性）」と同じ軸で比較する表に変更しました。

- `presentation_revised_slide3.pptx`：全6枚版。3枚目の本文・発表原稿を修正しています。
- `sensor_comparison_editable.pptx`：差し替え用の3枚目だけのPowerPoint。
- `sensor_comparison_preview.pdf`：改良した比較スライドの1ページプレビュー。
- `sensor_comparison_preview.png`：画像プレビュー。
- `speaker_notes_slide3_ja.txt`：更新した発表原稿と補足。

金属箔ひずみゲージ、導電性エラストマー、磁気式の3構成を同じ2項目で比較しています。数値条件を統一した性能ランキングではなく、代表的な構成の定性的な比較です。大きな曲げ変位と大きな材料ひずみは同じではなく、許容変形・線形性は材料、形状、配置、測定条件に依存します。

磁気式の利点は、変形する磁性体と磁場を読むHall素子を分け、Hall素子自体を引き伸ばさずに変形を読み取れる点として示しました。磁気式が自動的に線形になるという主張はせず、線形性は本研究で評価する項目として次のPMEの説明へつないでいます。

元資料の「圧電抵抗式」は「ピエゾ抵抗式（抵抗変化型）」と整理しています。低ヒステリシス研究の6.2%・ゲージ率13.8は、線形性と直接同一視できないため、参考文献とともに補足ノートへ移しました。

本文の図・文字はPowerPointで編集可能です。元資料の見出し線、ロゴ、フッターを使用しています。全6枚版では、修正対象以外の5枚のスライド本文・ノートのXMLを正規化して比較し、内容が元資料と同一であることを保存後に確認しました。3枚目の本文は画像貼り付けではありません。

フォントはYu Gothicです。PDFプレビューは日本語フォントをNoto Sans CJK JPへ代替してレンダリングしています。元の資料へ1枚だけ移す場合は、スライド全体をコピーし、「元の書式を保持」で貼り付けてください。
