## 本文の主張

1. **入出力の関係を知る** → 測定した磁場から曲げ量を求める。そのために感度・線形性を評価する。
2. **センシング原理を知る** → 磁場が変化する要因を調べ、形状・材料・計測位置を選ぶ根拠を得る。

初見の人向けに、曲げ変位を入力、磁場変化を出力とする関係図を最初に示しました。先行研究の詳細は補足に分け、本文の主張を短くしています。

## 使用方法

1枚目を元の7ページの差し替えとして使えます。2枚目は先行研究の根拠を説明する補足です。スライドまたは図をコピーして発表用のPowerPointへ貼り付けてください。

全てPowerPointの図形・線・矢印・テキストボックスで作成しており、画像の埋め込みはありません。文字は直接編集できます。図の形や色は、右クリックしてグループ解除すると個別に変更できます。指定フォントはYu Gothic（游ゴシック）です。

添付資料に合わせ、白背景・黒見出し・灰色の横線・研究室フッターを使っています。大学ロゴは入れていません。
