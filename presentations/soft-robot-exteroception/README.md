# ソフトロボットの外受容感覚を担う触覚センサ

## 編集用ファイル

[PowerPointを開く](./soft_robot_exteroception_editable.pptx)

1枚のスライドに、柔らかいロボットハンドが物体を把持し、表面の触覚センサで接触・押す力・滑りを検出する概念図を作成しました。

## 図の編集方法

- PowerPointの図形（角丸四角形・円・フリーフォーム）、線、矢印、テキストボックスで構成しています。PPTXに画像の埋め込みはありません。
- 図全体を一つのグループにまとめ、ロボット・センサ・説明欄などを内部のグループに分けています。
- 図を選択してコピーし、発表資料へ通常の貼り付けで挿入できます。画像として貼り付けると編集できなくなるため、通常の貼り付けを使ってください。
- 文字はダブルクリックして変更できます。
- 個別の形や色を変える場合は、右クリックから［グループ化］→［グループ解除］を選び、必要な単位まで解除してください。
- 曲線の輪郭はフリーフォーム図形です。［頂点の編集］で形状を変更できます。
- 指定フォントはYu Gothic（游ゴシック）です。異なる端末ではフォントの置換と表示を確認してください。

## 説明する範囲

触覚センサは外受容感覚を担うセンサの一例です。外受容感覚には視覚や距離検出なども含まれますが、この図では触覚に絞っています。実際に検出できる量は、センサの方式・配置・信号処理に依存します。特定のセンサが全てを検出できると示す実験結果ではありません。

## 確認

PPTXの再読込、ZIP/XML構造、テキストの配置、および画像・埋め込みメディアがゼロであることを確認しています。Microsoft PowerPointでの描画確認は実施していません。
